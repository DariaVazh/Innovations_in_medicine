
### Назначение папок

- **`config/`** — это «проект» Django. Здесь лежат общие настройки: язык, часовой пояс, список подключённых приложений, пути к статике и шаблонам. Один на весь сайт.
- **`core/`** — приложение для всего «административного»: вход врача, выход, страница настроек, главная. Всё, что не связано с пациентами напрямую.
- **`patients/`** — основное приложение. Модели «Пациент», «Исследование», «Результат ИИ», страницы списка и карточки пациента, загрузка МРТ и просмотрщик.
- **`static/`** — исходники интерфейса: CSS-файлы, JS-скрипты, логотип. Раздаются напрямую браузеру.
- **`templates/`** — HTML-шаблоны. Один базовый шаблон с сайдбаром, от которого наследуются остальные страницы.
- **`media/`** — сюда Django складывает загруженные пользователем файлы (МРТ-снимки). В Git не хранится, потому что это пользовательские данные.
